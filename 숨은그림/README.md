# 솔솔퍼즐(숨은그림)

장르를 골라 하는 숨은그림찾기. 새 게임을 누르면 그림 장르부터 고른다.

- 🎮 **게임**: 블록 마을(블록 친구·집·나무·차), 로봇 도시(로봇·빌딩·드론), 슬라임 모험(슬라임·성·버섯·물약)
- 📺 **만화**: 벚꽃 학교(큰 눈 만화 친구·학교·벚나무·고양이), 동물 마을(동물 친구·버섯 집·당근), 마법 학교(꼬마 마법사·마법탑·가마솥)
- 🎬 **영화**: 우주 대모험(외계인·로켓·UFO), 바닷속 탐험(물고기·산호·잠수함), 공룡 섬(아기 공룡·화산·야자수), 겨울 동화 마을(눈사람·전나무·이글루), 유령 저택(유령·호박·박쥐), 해적섬(해적·해적선·대포)
- 🎲 아무거나

- **초급**: 위·아래 그림에서 다른 곳 3곳 찾기. 큰 그림, 옷 색·모자·없어진 물건처럼 눈에 띄는 차이
- **중급**: 다른 곳 6곳. 친구가 많고 작아지고, 표정·옷 무늬·모자 색·창문 개수 같은 작은 차이도
- **고급**: 200명 넘게 모인 친구들 중에서 보기와 **똑같은 친구 3명** 찾기. 한 군데만 다른 닮은꼴이 40명쯤 섞여 있다. 두 손가락으로 확대
- 판마다 새로 그려지는 그림(전부 직접 그린 캐릭터·소품, 실제 작품 캐릭터는 쓰지 않음)
- 틀리게 누르면 +3초(고급 +5초), 힌트 3번(근처를 깜빡여 줌, +10초·+15초)
- 찾을 때 빨간 원·별가루·띵동, 신나는 남자 목소리 감탄(Nice!·Speedy!·Perfect!), 다 찾으면 팡파르·색종이
- 난이도별 최고 기록, 전체 순위표(서버 저장), 하던 판 자동 저장

## 아이폰에서 앱처럼 쓰기

1. Safari 로 게임 주소를 연다.
2. 아래쪽 공유 버튼 → **홈 화면에 추가**.
3. 홈 화면의 솔솔퍼즐(숨은그림) 아이콘으로 실행한다.
