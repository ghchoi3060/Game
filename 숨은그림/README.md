# 솔솔퍼즐(숨은그림)

귀여운 블록 친구들이 나오는 숨은그림찾기.

- **초급**: 위·아래 그림에서 다른 곳 3곳 찾기. 큰 그림, 옷 색·모자·없어진 물건처럼 눈에 띄는 차이
- **중급**: 다른 곳 6곳. 친구가 많고 작아지고, 표정·옷 무늬·모자 색·창문 개수 같은 작은 차이도
- **고급**: 공원에 모인 200명 넘는 블록 친구 중에서 보기와 **똑같은 친구 3명** 찾기. 한 군데만 다른 닮은꼴이 40명쯤 섞여 있다. 두 손가락으로 확대
- 판마다 새로 그려지는 그림(직접 그린 블록 친구·집·나무·차, 저작권 걱정 없음)
- 틀리게 누르면 +3초(고급 +5초), 힌트 3번(근처를 깜빡여 줌, +10초·+15초)
- 찾을 때 빨간 원·별가루·띵동, 신나는 남자 목소리 감탄(Nice!·Speedy!·Perfect!), 다 찾으면 팡파르·색종이
- 난이도별 최고 기록, 전체 순위표(서버 저장), 하던 판 자동 저장

## 아이폰에서 앱처럼 쓰기

1. Safari 로 게임 주소를 연다.
2. 아래쪽 공유 버튼 → **홈 화면에 추가**.
3. 홈 화면의 솔솔퍼즐(숨은그림) 아이콘으로 실행한다.
