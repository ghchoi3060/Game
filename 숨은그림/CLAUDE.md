# 솔솔퍼즐(숨은그림)

아이폰에서 링크로 여는 숨은그림찾기 웹앱(PWA). 다른 게임과 같은 디자인. 빌드 단계 없음 — 파일을 고치면 그대로 배포된다.
사용자 응답·문서·화면 문구는 한국어. 다른 회사 게임·캐릭터 이름(블록 게임 플랫폼, 군중 속 사람 찾기 그림책 등)과 그 그림은 쓰지 않는다. 그림은 전부 직접 그린 "블록 친구"와 소품.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면·스타일·앱 로직 전부. 누르기 판정, 힌트, 시간·벌점, 확대, 이펙트·소리·음성, 기록 |
| `engine.js` | 씨앗 난수로 장면 만들기, SVG 문자열로 그리기, 친구 판정 (`HiddenEngine()`) |
| `sw.js` | 오프라인 캐시. 캐시에 넣는 파일이 바뀌면 `CACHE` 버전을 올린다 |
| `manifest.webmanifest`, `icon.svg`, `icon-512.png` | 홈 화면 앱 정보·아이콘. PNG 는 `icon.svg` 를 512px 로 렌더링한 것 |

## 구조

- **난이도** `LEVELS`: 초급 `diff` 3곳, 중급 `diff` 6곳(장면 400×270), 고급 `crowd` 똑같은 친구 3명(장면 600×900).
- **블록 친구** `charSvg(c,x,y,s)`: 발 기준. 속성 `skin, shirt, pants, hat, hatC, face, acc, accC, pat, pose`(각각 목록 번호).
  `sig(c)` 는 보이는 속성만으로 만든 이름표(모자 없음·왕관이면 모자 색 무시, 칼·없음이면 소품 색 무시). "똑같다"는 이름표가 같다는 뜻.
  `mutate` 는 보이는 차이가 나는 속성 하나만 바꾼다.
- **틀린 그림** `genDiff(seed, lv)`: 해·구름(하늘) → 집·나무(지평선 y=170) → 친구·차·꽃·상자·동전(땅) 을 겹치지 않게 놓는다.
  차이는 서로 겹치지 않는 물건에서 고른다. 순서: 친구 → 집·차·나무 → 구름·해 → 작은 것. 초급은 큰 것 위주·작은 것 0개·없애기 1개까지, 중급은 작은 것 2개·없애기 2개까지.
  초급에서 바꾸는 것: 옷·바지 색, 모자, 소품, 팔 자세, 지붕·벽 색, 나무·차·꽃 색. 중급은 표정·무늬·모자 색·소품 색·창문·문·해 표정도.
  `diffs[k] = {id, box, kind, side?}` — `remove` 는 `side` 쪽 그림에서 그 물건이 빠진다. 두 그림 어느 쪽을 눌러도 같은 차이로 친다.
- **군중** `genCrowd(seed)`: 13열 × 21줄 자리에 흔들어 세우고(연못 자리 빼고) 약 240명. 보기와 똑같은 친구 3명(앞에 가리는 사람이 없는 자리), 한 군데만 다른 닮은꼴 40명, 나머지는 무작위(35% 는 보기와 같은 옷·모자를 입혀 헷갈리게). 무작위가 우연히 똑같으면 표정을 바꾼다.
  `personAt(sc,x,y)` 는 앞(나중에 그려진) 친구부터 찾는다.
- **누르기 판정**: 틀린 그림은 차이 상자를 최소 30×30 으로 넓혀 판정, 밖이면 틀림(+3초). 군중은 친구를 눌렀을 때만 판정(빈 땅은 둘러보는 중일 수 있어 벌점 없음), 다른 친구면 +5초.
- **힌트** 한 판 3번: 남은 것 하나의 근처를 노란 점선 원으로 깜빡임(정확한 자리 아님). 틀린 그림 +10초, 군중 +15초(그쪽으로 화면 이동).
- **확대(군중)**: `.crowd` 는 스크롤 상자(`touch-action: pan-x pan-y` 로 한 손가락은 기본 스크롤), 두 손가락 벌리기는 직접 처리해 손가락 가운데를 기준으로 확대. 1~4.5배, ＋ － 버튼, PC 는 Ctrl+휠. 확대 배율은 `hidden.zoom`(서버에는 안 올림). 벌린 직후 0.35초는 누르기 무시.
- **이펙트·소리**: 찾으면 빨간 원·별가루·"띵동"(찾을수록 음이 올라감)·진동, 틀리면 빨간 X·흔들림·+초 표시·"부부". 다 찾으면 팡파르·색종이·결과 카드.
- **감탄 음성**: 블록 게임과 같은 방식(폰 내장 음성 합성, 영어 남자 목소리, 짧고 높고 빠르게, 세기 3 이상 앞 함성). 찾을 때 Nice!·Found it!, 4초 안에 연달아 찾으면 Speedy!, 끝나면 Perfect!(틀림·힌트 없이)·New Record!·Great!. 스피커 버튼, 기본 켜짐(`hidden.voice`).
- **상태** `G`: `lv, seed, found[], time(벌점 포함), wrong, hints, over`. 장면은 씨앗으로 다시 만들어서 저장은 작다(`hidden.game`). 시간은 화면을 떠나거나 기록 탭·설명서일 때 멈춘다.
- **화면 크기**: 틀린 그림 한 장 폭 = `min(100%, (100svh − 282px) × 0.74)`(두 장이 한 화면에 들어가게), 군중 높이 = `100svh − 330px`. 위·아래 요소 높이를 바꾸면 이 값도 맞춘다. `dvh` 는 아이폰 주소창 때문에 쓰지 않는다.
- **버전 표시**: `VERSION` 을 맨 아래 줄·기록 탭·새 게임 알림에 보여 준다. 고칠 때마다 올린다.
- **저장**: `hidden.game`, `hidden.stats`(난이도별 played, won, best, recent), `hidden.lastLv`, `hidden.voice`, `hidden.seenManual`(처음 한 번 설명서). 서버 순위표는 `scores(game='hidden', level=난이도, time_sec=초)`, 짧은 시간이 위.

## 검증

- 엔진: 씨앗 300개 × 초급·중급에서 차이 수가 정확한지, 차이 상자가 안 겹치는지, 같은 씨앗이면 같은 장면인지. 군중 100개에서 똑같은 친구가 정확히 3명인지, 그 3명을 누르면 그 친구가 잡히는지.
- 화면: headless Chrome 에서 가짜 클릭으로 틀린 곳(+3초)·힌트·차이 전부 → 결과·기록. 고급은 닮은꼴(+5초) → 3명. 390px 폭은 iframe 으로 확인(headless 창은 500px 보다 좁아지지 않음).

## 배포

GitHub 저장소 `ghchoi3060/Game` 을 Pages 로 공개한다. 주소는 `https://ghchoi3060.github.io/Game/숨은그림/`.

## 서버 저장

`../common/cloud.js?v=4` 를 `data-game="hidden"` 으로 불러온다(`OWN` 에 `hidden` 항목). DB 는 게임 이름이 소문자 2~16자면 받아서 따로 바꿀 것이 없다.

## 게임 모음으로

왼쪽 위 아이콘·게임 이름(`.brand`)을 누르면 "게임 모음으로 갈까요?" 팝업(`../common/home.js`, 모든 게임 공통).

## 파일 버전

`engine.js?v=N`, `../common/*.js?v=N` 처럼 주소에 버전을 붙여 불러온다. 파일을 바꾸면 그 번호를 올리고 `sw.js` 의 SHELL·CACHE 도 맞춘다.
