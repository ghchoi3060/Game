# 솔솔놀이(계단)

끝없이 이어지는 하늘 계단을 오르는 게임. 폰에서 링크로 열고, 홈 화면에 추가하면 앱처럼 쓴다.

- **오르기**(초록): 보고 있는 쪽으로 한 칸. **방향 바꾸기**(파랑): 돌아서 한 칸. 계단이 없는 쪽으로 가면 떨어져서 끝.
- 시간 막대가 줄어들고, 오를 때마다 채워진다. 높이 갈수록 빨리 준다. 코인을 밟으면 조금 더 채워진다.
- 100층마다 하늘이 바뀐다: 파란 하늘 → 구름 위 → 노을 → 밤하늘 → 우주.
- 캐릭터 6종(토끼·고양이·곰·병아리·강아지·판다)을 고를 수 있고, 캐릭터마다 배경음악이 다르다(팝·펑키·폴카·칩튠·록·디스코, 모두 직접 만든 곡). 높이 갈수록 빨라진다.
- 10·25·50·100…층마다 칭찬(Good! Nice! Great! Excellent!…)과 음성.
- 친구와 동시에 하는 기능은 없다. 기록 탭의 전체 순위표와, 판이 끝난 뒤 **친구에게 자랑하기**(공유)로 겨룬다.
- 컴퓨터: ← 방향 바꾸기, → / 스페이스 오르기.
