# 솔솔퍼즐(블록)

블록을 끌어다 놓고 줄을 지우는 귀여운 블록 퍼즐.

- 8×8 판에 아래 블록 3개를 끌어다 놓는다. 가로·세로 한 줄이 꽉 차면 사라진다. 놓을 곳이 없으면 끝
- 끄는 블록은 손가락 위로 떠서 판을 가리지 않고, 놓을 자리 그림자와 지워질 줄이 미리 보인다. 톡 눌러 고른 뒤 칸을 눌러 놓아도 된다
- 점수: 칸 1점 + 줄 보너스(1줄 10, 2줄 30, 3줄 60…) × 연속(지운 줄 수만큼 올라감), 3초 안에 또 지우면 빠르게 보너스(+10, +20…)
- 판을 다 비우면 +300점과 **피버 타임**: 10초 동안 점수 2배, 무지개 테두리
- 난이도 초급·중급·고급: 초급은 1~3칸 블록 위주, 혼자 할 때는 3개 모두 놓을 수 있게 골라 주고 막히면 구조 블록 3번. 고급은 큰 블록이 많다. 최고 점수·순위표는 난이도별
- 혼자 하기: 최고 점수 도전, 하던 판은 자동 저장
- 친구와 하기(2명): 초대 링크로 참가, 두 사람에게 같은 블록이 같은 순서로. 화면 위에는 상대 이름·점수·상태만. 시간 제한(끝날 때까지·3분·5분)
- 블록 62종(대각선·십자·U·계단·긴 L 포함), 한 번에 나오는 3개는 서로 다른 모양
- 내려놓을 때 한 덩어리로 살짝 떨어져 반짝·통 튀기, 바깥으로 퍼지는 색 고리 두 겹, 판 눌림, 작은 +점수와 "띵띵" 종소리
- ♪ 버튼으로 신나는 배경음악(직접 만든 8비트 곡, 저작권 걱정 없음, 피버 때 빨라짐, 기본 꺼짐)
- 스피커 버튼: Great!·Perfect! 같은 감탄을 신나는 남자 목소리로 길게 외쳐 줌(폰 내장 음성, 기본 켜짐)
- 상황에 맞는 감탄 문구: 판 비움 Perfect!, 역전 Comeback!, 신기록 New Record!, 거의 찬 판에서 지움 Nice Save!, 2줄 이상 Double!·Triple!, 빠르게 연달아 Speedy!, 피버 중 On Fire!, 연속 3줄부터 Great! → … → Legendary!
- 줄을 이어서 지울수록 효과음이 점점 높아지고, 여러 줄은 한 줄씩 물결처럼 사라지고, 판 둘레가 노랑 → 빨강으로 달아오름
- 줄 지우기 효과음(많이·연속일수록 높게, 판 비우면 팡파르), 별가루, 점수 팝업, 리본, 3·2·1 시작, 불꽃놀이, 설명서, 기록, 전체 순위표(서버 저장)
