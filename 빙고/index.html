    빙고 설명서

    목표

    5×5 판에 1~25 숫자를 놓고, 돌아가며 숫자를 하나씩 불러요. 부른 숫자는 모두의 판에 동시에 표시돼요. 가로·세로·대각선으로 다섯 칸이 모두 표시되면 한 줄. 정한 줄 수(1·3·5줄)를 가장 먼저 채운 사람이 이겨요.

    숫자 배치

    • 랜덤 섞기: 숫자를 무작위로 다시 섞어요.
    • 직접 채우기: 판이 비워지고, 칸을 누를 때마다 1, 2, 3… 순서로 숫자가 놓여요. 원하는 자리에 놓아 보세요. 되돌리기로 하나씩 취소할 수 있어요.
    • 내 판은 다른 사람에게 보이지 않아요.

    숫자 부르기

    • 시작하면 제비뽑기로 부르는 순서를 정해요. 1번부터 차례대로 불러요.
    • 내 차례가 되면 판 테두리가 초록색으로 빛나요. 내 판에서 아직 표시되지 않은 칸을 누르면 그 숫자를 불러요. 친구와 할 때는 5초 안에 골라야 해요(봇과 할 때는 시간 제한 없음).
    • 다른 사람이 부른 숫자도 내 판에 자동으로 표시돼요. 판 아래에서 지금까지 부른 숫자를 볼 수 있어요.

    화면 보는 법

    • 위쪽 카드: 참가자와 각자 완성한 줄 수. 초록 테두리가 지금 부를 차례인 사람이에요.
    • B I N G O 글자: 내가 완성한 줄 수만큼 빨갛게 켜져요. 테두리가 있는 글자까지 켜면 이겨요.
    • 노란 칸은 불린 숫자, 빨간 칸은 완성된 줄이에요.

    친구와 하기 (최대 6명)

    • 친구 탭에서 이름을 적고 방 만들기. 이기는 줄 수를 고를 수 있어요.
    • 카카오톡으로 초대 보내기로 링크를 보내면, 친구가 링크를 열자마자 방에 들어와요. 방 코드 6자리로 들어올 수도 있어요.
    • 모두 숫자를 배치하고 준비 완료를 누르면, 방장이 시작을 눌러요. 부르는 순서는 시작할 때 제비뽑기로 정해요.
    • 내 차례가 오면 5초 안에 숫자를 골라야 해요. 시간 막대가 다 줄어들 때까지 안 고르면 내 줄에 도움이 되는 숫자가 자동으로 골라져요.
    • 방장이 카카오톡에 초대를 보내러 다녀와도 괜찮아요. 친구 폰이 방장을 계속 찾다가, 방장이 빙고 화면으로 돌아오면 바로 연결돼요.
    • 게임 중에 연결이 잠깐 끊겨도 자동으로 다시 들어와요. 그동안 내 차례는 자동으로 골라져요.
    • 누군가 빙고가 되면 띵동 소리가 나요. 아이폰이 무음 모드면 들리지 않아요.

    요령

    • 가운데 칸은 줄이 4개(가로·세로·대각선 둘)나 지나가요. 내가 부를 때는 여러 줄에 걸친 숫자를 고르세요.
    • 다른 사람이 부른 숫자도 내 줄을 채워 줘요. 거의 다 찬 줄의 남은 숫자를 노려 보세요.
