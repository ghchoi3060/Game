# 솔솔대국(빙고)

친구들과 함께하는 귀여운 숫자 빙고.

- 5×5 판에 1~25. 랜덤 섞기 또는 원하는 자리에 하나씩 놓는 직접 채우기
- 친구와 하기: 최대 6명. 방을 만들고 초대 링크를 카카오톡으로 보내면 링크를 연 친구가 바로 방에 들어온다
- 시작할 때 제비뽑기로 부르는 순서를 정하고, 내 차례에는 5초 안에 고른다(안 고르면 자동으로 골라짐)
- 이기는 줄 수: 1·3·5줄. 동시에 채우면 공동 우승
- 봇과 하기: 봇 1~5명, 실력 3단계(시간 제한 없음)
- 부를 때마다 판 아래 줄에 숫자 공이 굴러 들어오고(판을 가리지 않음), 줄을 채우면 칸이 빛나며 별가루·리본. 빙고면 B·I·N·G·O 공이 떨어지고 불꽃놀이와 "띵동" 소리
- 방장이 카카오톡에 다녀와도 친구 폰이 계속 다시 연결을 시도하고, 끊겨도 자동으로 다시 들어온다
- 설명서, 전적

## 아이폰에서 앱처럼 쓰기

1. Safari 로 게임 주소를 연다.
2. 아래쪽 공유 버튼 → **홈 화면에 추가**.
3. 홈 화면의 솔솔대국(빙고) 아이콘으로 실행한다.

## 친구와 하기

1. **친구** 탭에서 이름을 적고 이기는 줄 수를 골라 **방 만들기**.
2. **카카오톡으로 초대 보내기**로 링크를 보낸다.
3. 모두 숫자를 배치하고 **준비 완료** → 방장이 **시작**. 모두 화면을 켜 둔 채로 한다.
