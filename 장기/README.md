# 솔솔대국(장기)

탭하면 갈 수 있는 자리가 보이는 귀여운 장기.

- 봇 상대 10단계 난이도, 힌트·무르기
- 판마다 처음에 상차림 4가지(마상상마·상마마상·마상마상·상마상마) 중 골라서 시작
- 말은 실제 장기처럼 한자로 표시: 초는 흘림체(楚 车 包 马 象 士 卒), 한은 반듯한 해서(漢 車 包 馬 象 士 兵)
- 친구와 실시간 대전 — 방을 만들고 초대 링크를 카카오톡으로 보내면 끝
- 친구별 전적(몇 판, 몇 승 몇 패)과 봇 레벨별 전적

## 아이폰에서 앱처럼 쓰기

1. Safari 로 게임 주소를 연다.
2. 아래쪽 공유 버튼 → **홈 화면에 추가**.
3. 홈 화면의 솔솔대국(장기) 아이콘으로 실행한다.

## 친구와 두기

1. **친구** 탭에서 이름을 적고 **방 만들기**.
2. **카카오톡으로 초대 보내기**로 링크를 보낸다.
3. 친구가 링크를 열면 바로 대국이 시작된다. 둘 다 화면을 켜 둔 채로 둔다.

## 규칙에서 단순하게 한 부분

- 초가 먼저 둔다. 상차림은 각자 고르고, 둘 다 고른 뒤에 대국이 시작된다(봇은 무작위).
- 빅장(두 궁이 마주 보는 것)은 따로 처리하지 않는다.
- 둘 수 있는 수가 없으면 장군이 아니어도 진다(한수쉼 없음).
- 같은 국면이 3번 나오면 무승부.
- 200수가 되면 점수로 판정한다: 차 13, 포 7, 마 5, 상 3, 사 3, 졸 2, 한은 덤 1.5.
