# 솔솔퍼즐(스도쿠)

귀여운 스도쿠. 인터넷 없이도 폰 안에서 매번 새 문제를 만든다.

- 난이도 4단계: 쉬움·보통(외길 수만으로 풀림), 어려움·고수(후보를 따져 봐야 풀림). 모든 문제는 정답이 하나뿐
- 칸을 고르고 숫자 패드로 입력. 메모(후보 숫자), 되돌리기, 지우기, 힌트
- 틀린 숫자는 빨갛게, 같은 숫자와 같은 줄·칸·상자는 강조. 줄·칸·상자를 완성하면 반짝
- 난이도별 완성 수·최고 기록, 최근 완성한 판
- 아래 **설명서** 버튼을 누르면 규칙·조작·요령을 팝업으로 보여 준다
- PC 에서는 키보드도 된다: 숫자, 방향키, Backspace, N(메모), Ctrl+Z(되돌리기)

## 아이폰에서 앱처럼 쓰기

1. Safari 로 게임 주소를 연다.
2. 아래쪽 공유 버튼 → **홈 화면에 추가**.
3. 홈 화면의 솔솔퍼즐(스도쿠) 아이콘으로 실행한다.
