# 솔솔퍼즐(지뢰찾기)

귀여운 지뢰찾기. 폰 세로 화면에 맞춘 크기.

- 초급 9×9(지뢰 10), 중급 12×16(30), 고급 12×20(50)
- 첫 칸은 항상 안전하고 주변까지 넓게 열린다
- 찍지 않아도 논리로만 풀리는 판만 만들기(기본 켜짐, 끌 수 있음)
- 탭하면 열기, 길게 누르면 깃발. 깃발 모드 버튼을 켜면 탭이 깃발이 된다. PC 에서는 오른쪽 클릭이 깃발
- 열린 숫자를 누르면 주변 깃발 수가 맞을 때 나머지를 한 번에 연다
- 지뢰를 밟으면 폭발 이펙트와 함께 나머지 지뢰가 차례로 드러나고, 성공하면 꽃가루
- 난이도별 성공률·최고 기록, 최근 판

## 아이폰에서 앱처럼 쓰기

1. Safari 로 게임 주소를 연다.
2. 아래쪽 공유 버튼 → **홈 화면에 추가**.
3. 홈 화면의 솔솔퍼즐(지뢰찾기) 아이콘으로 실행한다.
